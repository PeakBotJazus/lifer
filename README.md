# Заря — текстовый симулятор выживания (Android)

## Как получить APK через GitHub
1. Создай новый репозиторий на github.com.
2. Загрузи в него все файлы проекта. Папка `.github` скрытая: проще всего через git
   (`git init && git add . && git commit -m init && git push`) или кнопка Add file → Upload files (перетащи всю папку).
3. Открой вкладку **Actions** → **Build APK** → **Run workflow** (или он запустится сам после push).
4. Через 3–5 минут открой завершённый запуск → внизу **Artifacts** → `zarya-apk`.
5. Распакуй zip, перекинь `app-debug.apk` на телефон и установи (разреши установку из неизвестных источников).

Игра лежит в `www/index.html`, правь её — и каждый push соберёт новый APK.
